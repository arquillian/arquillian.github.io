= Arquillian Cube Extension 1.3.0 Released
:sectids!:

New version of Arquillian Cube 1.3.0 has been released with new features and few bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Support for Network DSL in JUnit Rule*

Now you can use Network DSL to define a network using the JUnit Rule approach.

[listing,role="prettify",subs=verbatim]
----
@ClassRule
public static final NetworkDslRule network = new NetworkDslRule("mynetwork");
----

A new network with name pass:[<code>mynetwork</code>] and default parameters is created before test execution and destroyed at the end.

pass:[<i class="icon-star">]pass:[</i>] *Support for Dockerfile in Container Object DSL JUnit Rule*

In previous version you could only use Container Object DSL JUnit Rule approach with already built images. Now you can set to build images too.

You can set the pass:[<code>File</code>] directory where pass:[<code>Dockerfile</code>] is present or provide it as pass:[<code>ShrinkWrap</code>] archive.
