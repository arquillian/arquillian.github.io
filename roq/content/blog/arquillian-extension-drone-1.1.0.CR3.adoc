= Arquillian Drone Extension 1.1.0.CR3 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2012/09/11/arquillian-extension-drone-1-1-0-CR3/ (captured 2026-11-13).

After some thought we realized that the current options for configuration (and implementation for that matter) were too complicated. While pass:[<code>browserCapabilities</code>] allowed you to ignore the implementing class of WebDriver, you were still required to remember how to set up various capabilities.

We dropped the capability configuration support as you know it from CR1 and CR2 and replaced it with something much easier to use. You can now set up the capabilities directly as they come from WebDriver.

[discrete,role="highlights"]
=== Some of the highlights in this release

pass:[<i class="icon-star">]pass:[</i>] Direct capability mapping. Think of any WebDriver capability, such as pass:[<code>opera.no_restart</code>] or pass:[<code>acceptSSLCerts</code>], you can now specify them directly in pass:[<code>arquillian.xml</code>]:

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">firefox</property>
    <property name="opera.no_restart">true</property>
    <property name="acceptSSLCerts">false</property>
</extension>
----

pass:[<i class="icon-star">]pass:[</i>] Deprecated Arquillian Drone system properties configuration in favor of the system properties configuration provided by Arquillian Core. The old style of system properties still work, but using them will produce warnings in the log and will be removed completely in a later version.

In the previous pass:[<code>arquilian.xml</code>] snippet, pass:[<code>browserCapabilities</code>] would map to pass:[<code>arquillian.webdriver.browser.capabilities</code>]. The correct way to override this property is now pass:[<code>arq.extension.webdriver.browserCapabilities</code>]. With the new properties handling you can also provide the properties in a file by spcifying the file name in the pass:[<code>arquillian.properties</code>] system property.

The same apply to the qualifiers support. Given the following pass:[<code>arquillian.xml</code>] snippet you would now use pass:[<code>arq.extension.webdriver-myqualifier.browserCapabilities</code>] instead of the legacy pass:[<code>arquillian.webdriver.myqualifier.browser.capabilities</code>]:

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver-myqualifier">
    <property name="browserCapabilities">chrome</property>
</extension>
----

We hope that this will make Arquillian Drone easier to use, especially for people who have already tried to use pass:[<code>browserCapabilities</code>].

We look forward to hearing your feedback about this release in the http://community.jboss.org/en/arquillian[community forums]!
