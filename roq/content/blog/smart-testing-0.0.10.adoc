= Smart Testing 0.0.10 Released
:sectids!:

[discrete]
=== Excluded categories specification

Smart Testing is now supporting the exclusion of test categories.

In this release we introduced the pass:[<code>excludedCategories</code>] parameter for the pass:[<code>categorized</code>] strategy. +
When using this parameter, you specify the test categories you want to skip from execution, +
as you would in the pass:[<code>excludedGroups</code>] parameter of the pass:[<code>maven-surefire-plugin</code>].

The pass:[<code>excludedCategories</code>] works well with both *JUnit 4* and *JUnit 5* categories system (e.g the *pass:[@]Category* and *pass:[@]Tag* annotations)

This release also removes the pass:[<code>matchAll</code>] and pass:[<code>reversed</code>] parameters from the pass:[<code>categorized</code>] strategy, as the behaviour is replaced with the pass:[<code>excludedCategories</code>] parameters.
