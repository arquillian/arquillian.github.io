= Arquillian Portal Extension 1.0.0.Alpha2 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2012/10/18/arquillian-extension-portal-1-0-0-Alpha2/ (captured 2026-11-13).

The _Portal_ extension for Arquillian brings testing into the world of Portlets!

[discrete,role="highlights"]
=== Some of the highlights in this release

pass:[<i class="icon-star">]pass:[</i>] URL injection of portlets by name. pass:[<code>@PortalURL</code>] now supports defining the names of the portlets that you want rendered on the page of the injected URL. You can either specify a single portlet name, multiple, or leave it empty and it will load all portlets defined within pass:[<code>portlets.xml</code>] onto the page. Injecting a URL of a portlet page with the pass:[<code>MyPortlet</code>] portlet present is done by:

[.filename]
MyTest.java

[listing,role="prettify",subs=verbatim]
----
@ArquillianResource
@PortalURL("MyPortlet")
URL portletPage;
----

pass:[<i class="icon-star">]pass:[</i>] Annotation for marking portlet tests. pass:[<code>@PortalTest</code>] now represents a marker on a test class that signifies to _Portal_ extension implementations that a portlet test is being invoked. This enables for augmenting the test deployment with whatever information is needed for particular portlet containers to enable a portlet to be tested. It has the added benefit of decoupling a test needing to inject a pass:[<code>@PortalURL</code>] if the tests don’t require a URL to the portlet page.

Currently there are two implementations of this extension for use with https://github.com/jbossportletbridge/pluto-testing[Pluto] and https://github.com/jbossportletbridge/gatein-testing[GateIn] portal containers.

For examples on how to use these extensions with their respective portal containers, you can take a look at the https://github.com/jbossportletbridge/jbossportletbridge/tree/master/testsuites[testsuite] of JBoss Portlet Bridge.

We look forward to hearing your feedback about this release in the http://community.jboss.org/en/arquillian[community forums]!
