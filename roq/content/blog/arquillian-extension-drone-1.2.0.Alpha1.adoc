= Arquillian Drone Extension 1.2.0.Alpha1 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/01/15/arquillian-extension-drone-1-2-0-Alpha1/ (captured 2026-11-13).

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"] We’ve introduced new features and bugfixes in 1.2.0.Alpha1 while still preserving backwards compatibility with 1.1.0.Final. We fixed an annoying bug that made usage of some capabilities impossible and have delivered some Firefox goodies.

[discrete,role="highlights"]
=== Significant changes since 1.1.0.Final

pass:[<i class="icon-star">]pass:[</i>] Updated Selenium to 2.28.0 and introduced Selenium BOM::
+
--
Now you can switch to next Selenium version only by including following snippet in your pom.xml file.

[.filename]
pom.xml

[listing,role="prettify",subs=verbatim]
----
<dependencyManagement>
    <dependencies>
        <groupId>org.jboss.arquillian.selenium</groupId>
        <artifactId>selenium-bom</artifactId>
        <version>${version.selenium}</version>
        <type>pom</type>
        <scope>import</scope>
    </dependencies>
</dependencyManagement>
----
--

[.warning]
This snippet must be placed above arquillian-drone-bom in order to override Selenium versions.

pass:[<i class="icon-star">]pass:[</i>] Support for loading XPI into Firefox profile::
+
--
There is no need to work with a separate Firefox profile. Simply use the WebDriver generated one and let Drone install all extensions you need.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">firefox</property>
    <property name="firefoxExtensions">/path/to/extension1 "/path/to extension2/with/space"</property>
</extension>
----
--



pass:[<i class="icon-star">]pass:[</i>] Ability to set WebDriver logging level::
+
--
Drone allows to to set the logging level for Firefox WebDriver directly from Arquillian configuration.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">firefox</property>
    <property name="loggingPrefs">driver=INFO,profiler=WARNING</property>
</extension>
----
--

[.info]
Logging level are the same as for JUL, that is SEVERE, WARNING, INFO, CONFIG, FINE, FINER and FINEST.
