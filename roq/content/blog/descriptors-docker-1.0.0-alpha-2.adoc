:sectids!:

[discrete]
=== Usage improvements

With 1.0.0-alpha-2 we have improved the method chaining so you can write the pass:[<code>Dockerfile</code>] in a slightly more compact syntax with the help of a few new top level shortcuts:

[listing,role="prettify",subs=verbatim]
----
DockerDescriptor descriptor = Descriptors.create(DockerDescriptor.class)
        .from("jbossforge")
        .user("George");
descriptor.exportAsString();
----

The syntax from 1.0.0-alpha-1 is still valid:

[listing,role="prettify",subs=verbatim]
----
DockerDescriptor descriptor = Descriptors.create(DockerDescriptor.class)
        .from().name("jbossforge").up()
        .user().name("George").up();
descriptor.exportAsString();
----

And they both produce the same output:

[listing,role="prettify",subs=verbatim]
----
FROM jbossforge
USER George
----
