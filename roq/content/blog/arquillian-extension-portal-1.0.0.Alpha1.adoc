= Arquillian Portal Extension 1.0.0.Alpha1 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/01/15/arquillian-extension-android-1-0-0-Alpha2/ (captured 2026-11-13).

This is the first release of a new Arquillian Extension for assisting in the complex task of testing portlets in a portal environment.

[discrete,role="highlights"]
=== Some of the highlights in this release

pass:[<i class="icon-star">]pass:[</i>] Portal URL resource::
+
--
The SPI provides pass:[<code>PortalURLProvider</code>] for portal specific implementations to provide a different URL when injecting a pass:[<code>@ArquillianResource</code>] of type pass:[<code>URL</code>] into a test. All that is required to use it is add pass:[<code>@PortalURL</code>] onto the injection point, it’s that simple.
--

pass:[<i class="icon-star">]pass:[</i>] Additional portal deployments::
+
--
The SPI provides pass:[<code>PortalContainerDeploymentProvider</code>] for portal specific implementations to provide additional deployments that are required by the container to initiate the portal.
--

Currently there are two implementations of this extension for use with https://github.com/jbossportletbridge/pluto-testing[Pluto] and https://github.com/jbossportletbridge/gatein-testing[GateIn] portal containers.

For examples on how to use these extensions with their respective portal containers, you can take a look at the https://github.com/jbossportletbridge/jbossportletbridge/tree/master/testsuites[testsuite] of JBoss Portlet Bridge.

We look forward to hearing your feedback about this release in the http://community.jboss.org/en/arquillian[community forums]!
