= Arquillian Drone Extension 2.0.1.Final Released
:sectids!:

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"]

[discrete]
=== Chrome options

This release brings you a possibility to set chrome options for a pass:[<code>chromeDriver</code>] through your pass:[<code>arquillian.xml</code>] file. You can find all possible options that can be set on this https://sites.google.com/a/chromium.org/chromedriver/capabilities[web page]. +
The process of setting options uses a https://seleniumhq.github.io/selenium/docs/api/java/org/openqa/selenium/chrome/ChromeOptions.html[ChromeOptions class] which means that the parameter names (used in pass:[<code>arquillian.xml</code>]) are tightly coupled with the names of the set/add methods defined in the class. It is expected that the name of each parameter consists of:

++++
<pre>"chrome" + (name of the set/add method of <code>ChromeOption</code> class without first three chars)</pre>
++++

the whole string should be in camel case. For example, in case of an option *args* which is coupled with the method pass:[<a href="https://seleniumhq.github.io/selenium/docs/api/java/org/openqa/selenium/chrome/ChromeOptions.html#addArguments-java.util.List-">]pass:[<code>addArguments</code>]pass:[</a>], the parameter should look like this:

++++
<pre style='color:#000000;background:#ffffff;'><span style='color:#000080; '>&lt;</span><span style='color:#000080; '>property</span> <span style='color:#074726; '>name</span><span style='color:#0000ff; '>=</span><span style='color:#0000e6; '>"</span><span style='color:#0000e6; '>chromeArguments</span><span style='color:#0000e6; '>"</span><span style='color:#000080; '>></span><code>--first-argument --second-argument</code><span style='color:#000080; '>&lt;/</span><span style='color:#000080; '>property</span><span style='color:#000080; '>></span>
</pre>
++++

[.info]
Please notice that there are two methods named pass:[<i>]pass:[<code>addArguments</code>]pass:[</i>] in the pass:[<code>ChromeOptions</code>] class, one with a parameter which is a list of strings and second one with an array of strings – Drone treats them as a one single method (for other methods it is applied analogically).

[discrete]
==== Value formats

* In the cases, when the value can be an array or list of strings/files, you should specify all of them in one string separated by space (this is also applied for extensions as well as for encoded extensions).

* It is a little bit different in the case of experimental options. These options should be provided as set of key-value pairs, so we decided to use JSON format for it (can be in multiline format) – for example:

++++
<pre style='color:#000000;background:#ffffff;'><span style='color:#000080; '>&lt;</span><span style='color:#000080; '>property</span> <span style='color:#074726; '>name</span><span style='color:#0000ff; '>=</span><span style='color:#0000e6; '>"</span><span style='color:#0000e6; '>chromeExperimentalOption</span><span style='color:#0000e6; '>"</span><span style='color:#000080; '>></span><code>
{
  "perfLoggingPrefs": {
    "traceCategories": ",blink.console,disabled-by-default-devtools.timeline,benchmark"
  },
  "prefs": {
    "download.default_directory": "/usr/local/path/to/download/directory"
  }
}
</code><span style='color:#000080; '>&lt;/</span><span style='color:#000080; '>property</span><span style='color:#000080; '>></span>
</pre>
++++

[discrete]
==== Debug

If you struggle with passing required chrome options through the pass:[<code>arquillian.xml</code>] file, you can use a parameter pass:[<code>chromePrintOptions</code>] with a value pass:[<code>true</code>]:

++++
<pre style='color:#000000;background:#ffffff;'><span style='color:#000080; '>&lt;</span><span style='color:#000080; '>property</span> <span style='color:#074726; '>name</span><span style='color:#0000ff; '>=</span><span style='color:#0000e6; '>"</span><span style='color:#0000e6; '>chromePrintOptions</span><span style='color:#0000e6; '>"</span><span style='color:#000080; '>></span><code>true</code><span style='color:#000080; '>&lt;/</span><span style='color:#000080; '>property</span><span style='color:#000080; '>></span>
</pre>
++++

This ensures that Drone prints out the whole content of pass:[<code>ChromeOptions</code>] in a JSON format to the standard output.

[discrete]
=== Firefox 48

Since Mozilla has changed the internals of Firefox we strongly recommend to use new pass:[<a href=":https://github.com/mozilla/geckodriver">geckodriver</a>], as the community one is not compatible anymore. This applies for to all Firefox versions starting from 48. The gecko drivers can be downloaded https://github.com/mozilla/geckodriver/releases[here].

This Drone release partially supports these changes. By partially we mean you haved to download the geckodriver manually and specify a path to the driver using a parameter pass:[<code>firefoxDriverBinary</code>] there in your pass:[<code>arquillian.xml</code>] file:

++++
<pre style='color:#000000;background:#ffffff;'><span style='color:#000080; '>&lt;</span><span style='color:#000080; '>property</span> <span style='color:#074726; '>name</span><span style='color:#0000ff; '>=</span><span style='color:#0000e6; '>"</span><span style='color:#0000e6; '>firefoxDriverBinary</span><span style='color:#0000e6; '>"</span><span style='color:#000080; '>></span><code>/path/to/your/driver/binary</code><span style='color:#000080; '>&lt;/</span><span style='color:#000080; '>property</span><span style='color:#000080; '>></span>
</pre>
++++

Apart from this configuration, you also need to have Selenium 3 on your classpath – see below for detailed instructions.

[discrete]
=== Selenium version

As this release of Drone is a minor release and the latest Selenium release is in beta version, we decided stick to supported release in this version. In other words, Selenium 3 dependency is not automatically fetched by Drone 2.0.1.Final (the default one is still pass:[<code>2.53.1</code>]).

If you need to use the latest version of Selenium (for example together with geckodriver – see above), then the easiest way is specifying pass:[<code>selenium-bom</code>] dependency in a pass:[<code>dependencyManagement</code>] part of your pass:[<code>pom.xml</code>] file:

[.filename]
pom.xml

[listing,role="prettify",subs=verbatim]
----
 <!-- clip -->
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.jboss.arquillian.selenium</groupId>
            <artifactId>selenium-bom</artifactId>
            <version>3.0.0-beta3</version>
            <scope>import</scope>
            <type>pom</type>
        </dependency>
    </dependencies>
</dependencyManagement>
<!-- clip -->
----

[.info]
*IMPORTANT:* If you also use the pass:[<code>arquillian-drone-bom</code>] (or other BOMs), make sure that the pass:[<code>selenium-bom</code>] is placed pass:[<u>]beforepass:[</u>] other BOMs – to make the change effective.

The full support of Selenium 3 and geckodriver will be provided in the next release of Drone (2.1.0.Alpha1), so stay tuned.

We hope that you’ll enjoy our new stuff and look forward to hear your feedback.
