= Arquillian Algeron Extension 1.0.0.Alpha4 Released
:sectids!:

[.important]
*_Important note_*: This extension was called *Arquillian Pact* before version pass:[<code>1.0.0.Alpha5</code>], so you should use this name when pulling dependencies from Maven Central.

Arquillian Pact is an extension for writing contract-driven tests providing you seamless integration with well known https://docs.pact.io/[Pact] framework.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *pass:[<code>@Pact</code>] annotation can be used on the class level*

You can use pass:[<code>@Pact</code>] annotation on the class level, so method that defines a pact fragment just need to return pass:[<code>PactFragment</code>] object. In case of setting this annotation both on the class and method level, the one defined on the method will take precedence.

pass:[<i class="icon-star">]pass:[</i>] *Pact Publisher properties configuration*

You can configure Pact Publisher properties using Java System properties or Environment variables using Arquillian syntax. Any property value can be set using Java system property pass:[<code>${name:defaultValue}</code>] or using environment variable pass:[<code>${env.name:defaultValue}</code>]. pass:[<code>defaulValue</code>] will be used if referred property is not defined.

[discrete]
=== Bug fixing

pass:[<i class="icon-star">]pass:[</i>] *Using pass:[<code>skipDeployment</code>] with WildFly Swarm returns a NPE*

Skipping deployment for WildFly Swarm was resulting with NPE. This is because our URL provider was conflicting with the one Swarm implements (https://github.com/arquillian/arquillian-algeron/issues/44[++#++44]).

pass:[<i class="icon-star">]pass:[</i>] *Pact Publisher is not called when used with Gradle*

Pact Publisher is not called when used with Gradle due to a https://issues.gradle.org/browse/GRADLE-3411[bug in Gradle]. Since Publisher reacts to pass:[<code>AfterSuite</code>] and this event is not emitted when running in Gradle, we changed it to pass:[<code>AfterClass</code>]. This has a slight impact on the performance as publishing pacts happens after each test execution instead of being triggered once in a bulk after the whole test suite execution (https://github.com/arquillian/arquillian-algeron/issues/43[++#++43]).
