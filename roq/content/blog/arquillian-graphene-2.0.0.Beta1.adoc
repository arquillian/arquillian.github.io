= Graphene 2.0.0.Beta1 Released
:sectids!:

This is the first and probably also the last Beta release. We’ve focused on stabilization and documentation.

[discrete,role="highlights"]
=== Highlighted Changes

pass:[<i class="icon-star">]pass:[</i>] Stabilization of API::
+
--
In Beta1, we have stabilized the API and removed all the deprecated parts from Alpha5. The API is now considered final and there should be no more changes to it on the way to the Final release.
--



pass:[<i class="icon-star">]pass:[</i>] Getting Started Guide::
+
--
Thanks to the amazing effort of https://github.com/jhuska[Juraj Húska], we were able to rewrite the original link:/guides/functional_testing_using_graphene/[Functional Testing using Drone] guide to use Graphene 2. Even though it is targetting beginners of the Selenium WebDriver API, it will teache you best practices so you can write maintainable and efficient functional tests from day one.
--



pass:[<i class="icon-star">]pass:[</i>] Reference Documentation::
+
--
The https://docs.jboss.org/author/display/ARQGRA2/Home[Reference Documentation] was completed so that it reflects all features which are part of Graphene 2.0.
--



pass:[<i class="icon-star">]pass:[</i>] JavaDoc for API and SPI Available Online::
+
--
We have finalized documentation of Java classes for https://repository.jboss.org/nexus/service/local/repositories/releases/archive/org/jboss/arquillian/graphene/graphene-webdriver-api/2.0.0.Beta1/graphene-webdriver-api-2.0.0.Beta1-javadoc.jar/!/index.html[API] and https://repository.jboss.org/nexus/service/local/repositories/releases/archive/org/jboss/arquillian/graphene/graphene-webdriver-spi/2.0.0.Beta1/graphene-webdriver-spi-2.0.0.Beta1-javadoc.jar/!/index.html[SPI] and made them available online. You can bookmark those links since they won’t change in upcoming stable Graphene releases!
--

[.important]
A critical error with pass:[<code>@Location</code>] was found after the release of Beta1. See https://issues.jboss.org/browse/ARQGRA-373[ARQGRA-373] for more information. Expect a new release soon.

[discrete]
=== Final is due soon!

We are now pretty much done, and unless some serious issues or interoperability problems are identified in the community, we’ll release a candidate for Final release in a week, followed by a pass:[<code>2.0.0.Final</code>] shortly.

Be sure to check out the pass:[<code>Beta</code>] release, so we can avoid hitting any regressions once we get Final!
