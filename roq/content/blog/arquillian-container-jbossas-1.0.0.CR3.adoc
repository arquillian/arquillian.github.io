= Arquillian Container JBoss AS 1.0.0.CR3 Released
:sectids!:

[discrete]
=== Some of the highlights in this release

*JavaHome* configuration option now default to the Arquillian running JVM

Add configuration support for *portSet* to JBoss AS 5.1/6 Managed containers

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<arquillian xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xmlns="http://jboss.org/schema/arquillian"
  xsi:schemaLocation="
      http://jboss.org/schema/arquillian
      http://jboss.org/schema/arquillian/arquillian_1_0.xsd">

  <container qualifier="jboss">
    <property name="portSet">ports-01</property>
  </container>

</arquillian>
----

Setting the pass:[<code>portSet</code>] will automatically set the http and rmi ports to be use based on the pre defined sets in the JBoss AS configuration.

Add configuration support for *partition* to JBoss AS 4.2/5.1/6 Managed containers

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<arquillian xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xmlns="http://jboss.org/schema/arquillian"
  xsi:schemaLocation="
      http://jboss.org/schema/arquillian
      http://jboss.org/schema/arquillian/arquillian_1_0.xsd">

  <group qualifier="cluster">
    <container qualifier="jboss-1">
      <property name="partition">X-1</property>
    </container>
    <container qualifier="jboss-2">
      <property name="partition">X-1</property>
    </container>
  </group>

</arquillian>
----

Using the same pass:[<code>partition</code>] id on a pass:[<code>group</code>] of pass:[<code>containers</code>] defined in pass:[<code>arquillian.xml</code>] will allow them to form a cluster.
