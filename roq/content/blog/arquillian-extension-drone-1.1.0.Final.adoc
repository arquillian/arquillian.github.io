= Arquillian Drone Extension 1.1.0.Final Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2012/10/25/arquillian-extension-drone-1-1-0-Final/ (captured 2026-11-13).

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"] We’ve introduced new features in 1.1.0.Final while still preserving backwards compatibility with 1.0.0.Final. There’s now a much simpler way to configure Drone, better support for the Opera browser and support for browsers on iOS devices.

[discrete,role="highlights"]
=== Significant changes since 1.0.0.Final

pass:[<i class="icon-star">]pass:[</i>] Browser capabilities instead of pass:[<code>implementationClass</code>] and native capability configuration::
+
--
Think of any WebDriver capability, such as pass:[<code>opera.no_restart</code>] or pass:[<code>acceptSSLCerts</code>], and you can now specify it directly in pass:[<code>arquillian.xml</code>]:

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">opera</property>
    <property name="opera.no_restart">true</property>
    <property name="acceptSSLCerts">false</property>
</extension>
----
--



pass:[<i class="icon-star">]pass:[</i>] Support for reusable browsers::
+
--
Reusable browsers stay connected even if you finish the tests. This will speed up turnaroud when developing the application. Reusable browsers are based on top of remote browsers, so you’ll need Selenium Hub (run *selenium-server-standalone-2.25.0.jar*) running during your tests. This is how you enable them (pass:[<code>remoteAddress</code>] is optional, default value listed here):

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">chrome</property>
    <property name="remoteReusable">true</property>
    <property name="remoteAddress">http://localhost:4444/wd/hub</property>
</extension>
----
--



pass:[<i class="icon-star">]pass:[</i>] Better support for the Opera browser::
pass:[<i class="icon-star">]pass:[</i>] Support for browsers on iOS devices::
pass:[<i class="icon-star">]pass:[</i>] Deprecated Arquillian Drone system properties configuration::
+
--
The system properties configuration provided by Arquillian Core is now the preferred way to configure Arquillian Drone. The old style of system properties still work, but using them will produce warnings in the log and will be removed completely in a future version. Now use pass:[<code>arq.extension.extensionName.propertyName</code>] to override a value from arquillian.xml file
--
