= Smart Testing 0.0.7 Released
:sectids!:

[discrete]
=== Highlights of this release

In this release we ship more support to JUnit 5. Concretely we have added support for pass:[<code>@org.junit.jupiter.api.Tag</code>] and pass:[<code>@org.junit.jupiter.api.Tags</code>] annotations.

[discrete]
=== JUnit 5 tag support

In this realease we have added support for pass:[<code>@org.junit.jupiter.api.Tag</code>] and pass:[<code>@org.junit.jupiter.api.Tags</code>] annotations in pass:[<code>categorized</code>] strategy. +
Tags is the way to categorize tests in JUnit 5 and a categorized test looks like:

[listing,role="prettify",subs=verbatim]
----
@Tag("first")
@Tag("second")
public class FirstAndSecondTaggedClass {
}
----

Then you need to configure the strategy by setting pass:[<code>categories</code>] property with tag value.

[discrete]
