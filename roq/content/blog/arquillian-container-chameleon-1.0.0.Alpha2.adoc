= Arquillian Container Chameleon 1.0.0.Alpha2 Released
:sectids!:

[discrete,role="highlights"]
=== What’s included in the Alpha2 release?

pass:[<i class="icon-star">]pass:[</i>] Allow non JBossAS/WildFly containers to be configured::
+
--
In Alpha1 the definition for the pass:[<code>JBoss AS / WildFly</code>] containers were hard coded. In Alpha2 we’ve externalized the configuration. By default pass:[<code>Chameleon</code>] will read the classpath resource https://github.com/arquillian/arquillian-container-chameleon/blob/1.0.0.Alpha2/src/main/resources/chameleon/default/containers.yaml[chameleon/default/containers.yaml] which is a yaml file that describes things like:

* target names
* version ranges
* adapter dependencies
* distribution download description
* configuration options to update
--



pass:[<i class="icon-star">]pass:[</i>] Updates to configuration::
+
--
All configuration options that belong to the pass:[<code>Chameleon</code>] container are now prefixed with '`chameleon`'.

That means that the configuration option from Alpha1 '`target`' is now called '`chameleonTarget`'.
--



pass:[<i class="icon-star">]pass:[</i>] Define where distributions are found or downloaded::
+
--
In Alpha1 distribution downloads would be placed in pass:[<code>target/server</code>] if you were using pass:[<code>Maven</code>] or pass:[<code>bin/server</code>] if you were using pass:[<code>Gradle</code>] as the build system.

In Alpha2 we’ve introduced a new configuration option named pass:[<code>chameleonDistributionDownloadFolder</code>]. Via this option you can define where the distribution should be downloaded if you use the auto download feature of pass:[<code>Chameleon</code>].

Optionally you can define pass:[<code>chameleonDistributionDownloadFolder</code>] to be pass:[<code>TMP</code>] and pass:[<code>Chameleon</code>] will create a new temp folder based on the pass:[<code>java.io.temp</code>] system property defined in the JVM.
--



pass:[<i class="icon-star">]pass:[</i>] Define a custom container configuration file::
+
--
If you want to create your own version of the default pass:[<code>containers.yaml</code>] file, you can configure pass:[<code>Chameleon</code>] to point to it via the configuration option pass:[<code>chameleonContainerConfigurationFile</code>]. Not this is loaded as a classloader resource and would need to be on the classpath, and not as a file on the file system.
--



pass:[<i class="icon-star">]pass:[</i>] Support GlassFish 3.x/4.1 container definitions::
+
--
You can now use some of the following pass:[<code>chameleonTarget</code>] definitions to run against the pass:[<code>GlassFish</code>] server:

* glassfish:3.1:managed
* glassfish:4.0:remote
--
