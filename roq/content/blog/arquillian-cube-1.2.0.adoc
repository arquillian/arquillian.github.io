= Arquillian Cube Extension 1.2.0 Released
:sectids!:

New version of Arquillian Cube 1.2.0 has been released with new features and few bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Adds annotation for sleeping before each test*

You can annotate a class with pass:[<code>@Sleep</code>] annotation so before starting executing the tests, the execution is slept by the amount of milliseconds set there.

This annotation also supports timespan format. For example pass:[<code>@Sleep(&quot;1m30s&quot;)</code>] set a waiting of 1 minute and a half.

pass:[<i class="icon-star">]pass:[</i>] *Add support for pass:[<code>@HealthCheck annotation</code>]*

pass:[p.] You can annotate a class with pass:[<code>@HealthCheck</code>] annotation so before starting executing the tests, the execution is slept until the health check passes.

For example pass:[<code>@HealthCheck(&quot;/myservice/healthcheck&quot;)</code>] waits until the given endpoint returns an Http Code 200.

pass:[<i class="icon-star">]pass:[</i>] *JUnit Rule for Container Object DSL approach*

Now you can use Container Object DSL without pass:[<code>Arquillian</code>] runner. You only need to use a pass:[<code>JUnit Rule</code>] for this purpose.

[listing,role="prettify",subs=verbatim]
----
 @ClassRule
 public static ContainerDslRule redis = new ContainerDslRule("redis:3.2.6")
                                            .withPortBinding(6379);
----

Before executing test class, a new Docker container using Redis image is boot up and stopped after all tests.
