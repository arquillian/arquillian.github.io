= ShrinkWrap Descriptors 2.0.0-alpha-8 Released
:sectids!:

[discrete]
=== Highlights in this release

pass:[<i class="icon-star">]pass:[</i>] Support for JBossAS/WildFly module.xml::
+
--
You can now programmatically create pass:[<code>module.xml</code>] descriptors using the following API:

[listing,role="prettify",subs=verbatim]
----
 ModuleDescriptor module = Descriptors.create(ModuleDescriptor.class)
    .addDefaultNamespaces()
    .name("some.module")
    .slot("impl")
----

[listing,role="prettify",subs=verbatim]
----
ModuleAliasDescriptor module = Descriptors.create(ModuleAliasDescriptor.class)
    .addDefaultNamespaces()
    .name("some.module")
    .slot("impl")
    .targetName("some.other.module")
    .targetSlot("main");
----

[listing,role="prettify",subs=verbatim]
----
ModuleAbsentDescriptor module = Descriptors.create(ModuleAbsentDescriptor.class)
    .addDefaultNamespaces()
    .name("some.module")
    .slot("impl");
----

These descriptors can be found in the pass:[<code>shrinkwrap-descriptors-api-jboss</code>] module.
--



pass:[<i class="icon-star">]pass:[</i>] Support for JBossAS/WildFly jboss-deployment-structure.xml::
+
--
And specially configure the deployment structure of your deployment via the pass:[<code>jboss-deployment-structure.xml</code>] descriptor:

[listing,role="prettify",subs=verbatim]
----
JBossDeploymentStructureDescriptor jbossDeployStructur = create()
    .addDefaultNamespaces()
    .earSubdeploymentsIsolated(false)
    .getOrCreateDeployment()
        .getOrCreateModuleAlias().name("name1").slot("slot1").up()
            .getOrCreateExports().createExclude().path("path1").up().up();
----

These descriptors can be found in the pass:[<code>shrinkwrap-descriptors-api-jboss</code>] module.
--
