= Arquillian Drone Extension 1.2.0.Beta1 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/09/04/arquillian-extension-drone-1-2-0-Beta1/ (captured 2026-11-13).

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"]

This release brings you better Firefox support and configurable browser instantiation timeout.

pass:[<br/>]

[discrete]
=== What’s new in Drone 1.2.0.Beta1?

pass:[<i class="icon-star">]pass:[</i>] Browser capabilities shorthand::
+
--
Since the pass:[<code>browserCapabilities</code>] property was made the default way to set the type of WebDriver you wanted, people have been asking for a simpler name. Now you can just use the pass:[<code>browser</code>] property instead. While the original property is marked deprecated, we won’t be removing it in the 1.x series.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <!-- since now, you can simply write "browser" -->
    <property name="browser">chrome</property>
</extension> 
----
--



pass:[<i class="icon-star">]pass:[</i>] Global Drone configuration in arquillian.xml::
+
--
Since 1.2.0.Alpha3, Selenium and WebDriver instances are retrieved using a time limit, avoiding your tests to get stuck. This limit is now 60 seconds by default and can be modified in _arquillian.xml_ file globally for all supported Drones. Also, the limit is disabled if you set pass:[<code>arquillian.debug</code>] property to pass:[<code>true</code>].

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="drone">
    <!-- set this to zero if you want to disable timeout -->
    <property name="instantiationTimeoutInSeconds">0</property>
</extension> 
----
--



pass:[<i class="icon-star">]pass:[</i>] Firefox goodies::
+
--
WebDriver configuration now accepts two new configuration properties, pass:[<code>firefox_profile</code>] and pass:[<code>firefoxUserPreferences</code>]. While the first one is not really new, it allows you to set a path to the Firefox profile template, the latter makes it possible to modify _prefs.js_ for the created Firefox profile.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="firefox_profile">/path/to/profile</property>
    <property name="firefoxUserPreferences">/path/to/preferences/file</property>
</extension> 
----
--



pass:[<i class="icon-star">]pass:[</i>] Updated to WebDriver 2.35.0::
+
--
Arquillian Drone uses Selenium 2.35.0 by default. Due to recent WebDriver API changes(++>++=2.34.0), we do not recommend the use of the _selenium-bom_ in pass:[<code>&lt;dependencyManagement&gt;</code>] to downgrade to a older Selenium version. For the very same reason, we recommend you to update link:/blog/2013/09/04/arquillian-graphene-2-0-0-Alpha5/[Arquillian Graphene to 2.0.0.Alpha5] that is compatible with latest Selenium. Also note that Selenium 2.35.0 deprecated the pass:[<code>IPhoneDriver</code>], so Drone did the same.
--

Drone is based on top of Arquillian Core 1.1.0.Final. Please update your pass:[<code>&lt;dependencyManagement&gt;</code>] sections if you’re using Arquillian BOM (artifactId: pass:[<code>arquillian-bom</code>]) together with Arquillian Drone BOM.

I’d like to thank everybody involved in this release. _You guys make testing a breeze!_

We hope that you’ll enjoy the improvements and look forward to hear your feedback in the http://community.jboss.org/en/arquillian[community forums].
