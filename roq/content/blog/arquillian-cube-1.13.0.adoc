= Arquillian Cube Extension 1.13.0 Released
:sectids!:

We are delighted to announce a new version of Arquillian Cube 1.13.0 with a bunch of awesome features related to Docker and bug fixes.

[.important]
*_Important change_*: One of the important fixes we introduced is about handlings multiple values for pass:[<code>env.dependencies</code>] and pass:[<code>wait.for.service.list</code>]. We have changed the separation char from white-space to comma-separated, so to migrate to a new version, just add a comma instead of white space in the property to separate each of the element.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Allow parallelization of networks*

Now you can use the star pattern for networks. It works the same as the container star pattern.

[listing,role="prettify",subs=verbatim]
----
<property name="dockerContainers">
     networks:
       testnetwork*:
         driver: bridge
     tomcat*:
       image: tutum/tomcat:8.0
      portBindings: [8080/tcp]
       networkMode: testnetwork*
     ping*:
       image: jonmorehouse/ping-pong
       exposedPorts: [8089/tcp]
       networks:
         - testnetwork*
</property>
----

pass:[<i class="icon-star">]pass:[</i>] *Allow docker configuration to be loaded from the classpath*

Currently Docker definition files were loaded from file (relative or absolute). In this version, pass:[<code>dockerContainersResource</code>] where you can specify a file containing the container definitions on the Java classpath.

pass:[<i class="icon-star">]pass:[</i>] *Use comma to separate multiple values in arquillian.xml*

pass:[<code>env.dependencies</code>] or pass:[<code>wait.for.service.list</code>] properties have changed the separation char from white-space to comma-separated. To migrate to new version, just add a comma instead of white space in the property to separate each of the element.
