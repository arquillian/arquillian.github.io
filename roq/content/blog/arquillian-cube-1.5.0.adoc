= Arquillian Cube Extension 1.5.0 Released
:sectids!:

New version of Arquillian Cube 1.5.0 has been released with new features and bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Set System Properties with Docker container information*

When running a test next System Properties should be available:

* pass:[<code>arq.cube.docker.host</code>] setting the docker host ip.

And for each docker container defined:

* pass:[<code>arq.cube.docker.&lt;cube_id&gt;.ip</code>] with container ip.
* pass:[<code>arq.cube.docker.&lt;cube_id&gt;.internal.ip</code>] with container internal ip.
* pass:[<code>arq.cube.docker.&lt;cube_id&gt;.port.&lt;exposed_port&gt;</code>] with binding port of giving exposed port.
