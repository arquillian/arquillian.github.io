= Arquillian Drone Extension 1.2.0.Alpha2 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/05/03/arquillian-extension-drone-1-2-0-Alpha2/ (captured 2026-11-13).

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"] We’ve please to announce Drone 1.2.0.Alpha2. This release brings you PhantomJS support and an easier model for future extensions.

pass:[<br/>]

[discrete,role="highlights"]
=== Significant changes since 1.2.0.Alpha1

pass:[<i class="icon-star">]pass:[</i>] Support for PhantomJS::
+
--
PhantomJS allow you to run headless tests on a real browser. And Drone supports it out of the box.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">phantomjs</property>
    <property name="phantomjs.binary.path">/path/to/phantomjs.binary</property>
</extension>
----
--



pass:[<i class="icon-star">]pass:[</i>] Automatic Augmentation::
+
--
RemoteWebDriver instances are now automatically augmented.
--



pass:[<i class="icon-star">]pass:[</i>] Discarding cookies for reusable browsers::
+
--
You can now use reusable browser while ensuring cooking from previous test runs do not affect current test run. The default behavior is to delete the cookies. If you want to preserve previous behavior, you can use the pass:[<code>reuseCookies</code>] configuration option.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="reuseCookies">true</property>
</extension>
----
--

This release breaks implementation compatibility with previous Drone releases. You should not be affected by this unless you use Drone combined with other projects that depend on more then just SPI, such as Graphene 2. We are releasing new compatible versions of these projects; such as Graphene 2.0.0.Alpha4. +
These changes were done in order to make Drone more reusable by third party projects to avoid similar problems in future.

I’d like to thank everybody involved in this release. _You guys make testing a breeze!_

We hope that you’ll enjoy the improvements and look forward to hear your feedback in the http://community.jboss.org/en/arquillian[community forums].
