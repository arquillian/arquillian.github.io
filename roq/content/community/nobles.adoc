          <p>This page recognizes community members that have helped shape Arquillian during each release cycle, either though code contributions, participation or advocacy. For donating their time, effort and patience to make Arquillian a better testing framework for the benefit of the community, we award each of them the title Arquillian Noble.</p>

            <p class="info">
              <span>Community members may be crowned multiple times. Once a contributor becomes a team member, subsequent contributions are not listed here (team members are noble by default).</span>

== Advocates, Innovators and Early Adopters

* link:https://community.jboss.org/people/petemuir[Pete Muir] - Co-founder of Arquillian. Created JBoss Test Harness, the precursor to Arquillian.
* link:https://community.jboss.org/people/cheyenneweaver[Cheyenne Weaver] - Brought Ike to life and gave Arquillian a link:http://design.jboss.org/arquillian[visual identity]
* link:https://community.jboss.org/people/adriancole[Adrian Cole] - Took Arquillian to the clouds (via link:http://jclouds.org[jclouds]); advocates it as a Java cloud power tool
* link:https://community.jboss.org/people/pbakker[Paul Bakker] - Created and maintains the Arquillian Forge plugin (link:https://issues.jboss.org/browse/SEAMFORGE-146[SEAMFORGE-146])
* link:https://community.jboss.org/people/jesper.pedersen[Jesper Pedersen] - Implemented the IronJacamar (embedded JCA) container adapter
* link:https://community.jboss.org/people/germanescobar[German Escobar] - Wrote about link:http://community.jboss.org/wiki/TestingaJMXPortableExtensionforCDI[testing a JMX CDI extension with Arquillian]
* link:https://community.jboss.org/people/michaelschuetz[Michael Schuetz] - Setup the link:http://github.com/arquillian-sandbox[Arquillian sandbox] repository, created quickstart projects, researched and wrote Seam 2 extension
* link:https://community.jboss.org/people/adamw[Adam Warski] - Worked out a solution for doing link:http://www.warski.org/blog/?p=325[efficient database-oriented testing]
* link:https://community.jboss.org/people/myfear[Markus Eisele] - Covered Arquillian in link:http://blog.eisele.net/2011/03/new-article-for-latest-jaxmag-java-ee-6.html[Java Tech Journal March 2011]
* link:https://community.jboss.org/people/CosminMartinconi[Cosmin Martinconi] (mentor: link:https://community.jboss.org/people/jakobk[Jakob Korherr]) - link:http://socghop.appspot.com/gsoc/student_project/show/google/gsoc2010/apache/t127230758773[GSoC 2010 project] to create an link:http://wiki.apache.org/myfaces/AutomatedWebappTest_Status[automated webapp test suite for MyFaces] based on the Arquillian SPI (link:http://www.jakobk.com/2010/09/myfaces-webapptest-meets-apache-svn[wrap-up])
* link:https://community.jboss.org/people/meetoblivion[John Ament] - Wrote about link:http://john-ament.blogspot.com/2010/03/writing-property-loader-in-java-ee-6.html[testing a property loader CDI extension with Arquillian]
* link:https://community.jboss.org/people/swd847[Stuart Douglas] - Converted Weld extensions tests to Arquillian, uses Arquillian to test fakereplace
* link:https://community.jboss.org/people/jganoff[Jordan Ganoff] - Wrote about link:http://community.jboss.org/wiki/Seam3JMSModuleTestingwithArquillian[testing the Seam JMS module with Arquillian]
* link:https://community.jboss.org/people/lincolnthree[Lincoln Baxter III] - Wrote about link:http://ocpsoft.com/seam/cdi-powered-unit-testing-using-arquillian/[CDI-powered unit testing with Arquillian], uses Arquillian to test Seam Forge
* link:https://community.jboss.org/people/cbrock[Mike Brock] - Adopted Arquillian for testing Errai
* link:https://community.jboss.org/people/bob.mcwhirter[Bob McWhirter] and link:https://community.jboss.org/people/jcrossley[Jim Crossley] - Experimented combining Arquillian with JRuby and RSpec in link:http://torquebox.org[TorqueBox]

Thanks to all of you who have tweeted about link:http://search.twitter.com/search?q=%23Arquillian[#Arquillian] as well!
