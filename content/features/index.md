# Arquillian Features

Arquillian is an innovative testing platform for the JVM that enables developers to easily create automated integration, functional and acceptance tests for Java middleware.

## Test Real Components

Arquillian brings your test to the runtime so you can focus on testing your application's behavior rather than managing the runtime. Using Arquillian, you can develop a comprehensive suite of tests from the convenience of your IDE and run them in any IDE, build tool or continuous integration environment.

## In-Container Testing

Arquillian deploys your test archives to the target container and executes the tests inside the container. This means your tests are executed in the same environment as they would be in production, giving you more accurate results.

## Dependency Injection

Arquillian supports dependency injection directly into your test class. This means you can test CDI beans, EJBs, and other components that rely on container services without having to mock those services.

## Extensible Architecture

Arquillian's architecture is highly extensible, allowing you to add support for new containers, test frameworks, and extensions. This makes it a future-proof choice for your testing needs.

## Container Support

Arquillian supports a wide range of containers, including:

- JBoss AS / WildFly
- GlassFish
- WebLogic
- WebSphere
- Tomcat
- Jetty
- Weld SE
- OpenEJB
- And many more...

## Test Framework Integration

Arquillian integrates with popular test frameworks:

- JUnit
- TestNG

## Extensions

Arquillian has a rich ecosystem of extensions:

- **Drone**: Browser automation and WebDriver integration
- **Graphene**: Rich WebDriver extensions and Ajax support
- **Persistence**: Database testing
- **Spring**: Spring Framework integration
- **Cube**: Docker container integration
- **Chameleon**: Simplified container configuration
- **Algeron**: Consumer-driven contract testing
- **Smart Testing**: Intelligent test execution order

## Microservices Testing

Arquillian Cube allows you to test microservices by managing Docker containers as part of your test lifecycle. This makes it possible to test complex distributed systems with ease.

## Cloud Testing

Arquillian supports testing in cloud environments, allowing you to test your applications in the same environment they will run in production.
