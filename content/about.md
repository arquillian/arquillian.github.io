# About Arquillian

Arquillian is an innovative and highly extensible testing platform for the JVM that enables developers to easily create automated integration, functional and acceptance tests for Java middleware.

## What is Arquillian?

Arquillian is a testing platform that simplifies integration testing for Java middleware. It handles all the plumbing of container management, deployment, and framework initialization so you can focus on the task at hand: writing your tests.

Arquillian brings your test to the runtime so you can focus on testing your application's behavior rather than managing the runtime. Using Arquillian, you can develop a comprehensive suite of tests from the convenience of your IDE and run them in any IDE, build tool or continuous integration environment.

## Key Features

- **In-container testing**: Test your code inside the container, not outside it
- **Real tests, not mock tests**: Test real components in a real environment
- **Dependency injection**: Use CDI, Spring, or other DI frameworks in your tests
- **Extensible**: Add support for new containers, test frameworks, and extensions
- **Integration with existing tools**: Works with JUnit, TestNG, Maven, Gradle, and more

## Project History

Arquillian was created by the JBoss Community in 2010 to address the need for a simple way to test Java EE applications. Since then, it has grown into a comprehensive testing platform with support for a wide range of containers and frameworks.
