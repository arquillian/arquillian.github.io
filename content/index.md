## What is Arquillian?

Arquillian is an innovative and highly extensible testing platform for the JVM that enables developers to easily create automated integration, functional and acceptance tests for Java middleware.

Arquillian brings your test to the runtime so you can focus on testing your application's behavior rather than managing the runtime. Using Arquillian, you can develop a comprehensive suite of tests from the convenience of your IDE and run them in any IDE, build tool or continuous integration environment.

## Why Arquillian?</h2>

### Test Real Components

Arquillian tests your application components in a real runtime environment, not a simulated one. No more mocks. No more container simulation. The real deal.

### Dependency Injection
Arquillian supports dependency injection directly into your test class. This means you can test CDI beans, EJBs, and other components that rely on container services without having to mock those services.

### Extensible Architecture
Arquillian's architecture is highly extensible, allowing you to add support for new containers, test frameworks, and extensions. This makes it a future-proof choice for your testing needs.

### Container Support
Arquillian supports a wide range of containers, including JBoss AS / WildFly, GlassFish, WebLogic, WebSphere, Tomcat, Jetty, Weld SE, OpenEJB, and many more.
