= Arquillian Core 1.1.15.Final Released
:sectids!:

We have released yet another minor version of Arquillian Core. This time with long lasted fix for TestNG test failures reporting.

[discrete]
=== Support for new TestNG versions

Finally, we have a fix landed in https://github.com/cbeust/testng/issues/1426[TestNG] and Arquillian Core, supporting newer versions of TestNG. So grab it while it’s hot.

One important note here if you want to rely only on Maven Central repository – TestNG pass:[<code>6.12</code>] is not in Maven Central and pass:[<code>6.13</code>] refers to JCommander version which is also not in Maven Central (sic!). You can read about the problem https://github.com/cbeust/testng/issues/1506[here].

You have two options to mitigate it:

* Use recently published TestNG pass:[<code>6.13.1</code>] having proper JCommander dependency
* Add version of JCommander which is published to Maven Central before TestNG dependency (e.g. pass:[<code>1.69</code>] or pass:[<code>1.72</code>]).

[listing,role="prettify",subs=verbatim]
----
<dependency>
  <groupId>com.beust</groupId>
  <artifactId>jcommander</artifactId>
  <version>1.69</version>
  <scope>test</scope>
</dependency>
<dependency>
  <groupId>org.testng</groupId>
  <artifactId>testng</artifactId>
  <version>${version.testng}</version>
  <scope>test</scope>
</dependency>
----
