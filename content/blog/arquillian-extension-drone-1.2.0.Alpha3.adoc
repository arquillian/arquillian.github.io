= Arquillian Drone Extension 1.2.0.Alpha3 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/08/17/arquillian-extension-drone-1-2-0-Alpha3/ (captured 2026-11-13).

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"] This release brings you PhantomJS binary auto resolution and a major update of SPI’s for extension creators.

pass:[<br/>]

[discrete,role="highlights"]
=== Significant changes since 1.2.0.Alpha2

pass:[<i class="icon-star">]pass:[</i>] Support for PhantomJS binary auto resolution::
+
--
The PhantomJS binary is now automatically resolved if it’s not found using the pass:[<code>phantomjs.binary.path</code>] property. So you don’t have to specify this property anymore.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="webdriver">
    <property name="browserCapabilities">phantomjs</property>
</extension> 
----
--



pass:[<i class="icon-star">]pass:[</i>] New SPI Model::
+
--
If you are writing your own Arquillian extension and you would like to use Arquillian Drone, it is now much simpler. Drone exposes events for browser configuration, creation, enrichement, enhancement and disposal, giving you full control of its lifecycle. If you have used the old SPI model, there are now other interfaces you might need to implement.
--



pass:[<i class="icon-star">]pass:[</i>] Updated to WebDriver 2.33.0::
+
--
Arquillian Drone uses WebDriver 2.33.0 by default. You can still use pass:[<code>selenium-bom</code>] to override the WebDriver versions if needed.
--

Drone is now based on top of Arquillian Core 1.1.1.Final. Please update your pass:[<code>&lt;dependencyManagement&gt;</code>] sections if you’re using Arquillian BOM (artifactId: pass:[<code>arquillian-bom</code>]) together with Arquillian Drone BOM.

I’d like to thank everybody involved in this release. _You guys make testing a breeze!_

We hope that you’ll enjoy the improvements and look forward to hear your feedback in the http://community.jboss.org/en/arquillian[community forums].
