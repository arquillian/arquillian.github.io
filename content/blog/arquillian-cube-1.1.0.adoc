= Arquillian Cube Extension 1.1.0 Released
:sectids!:

New version of Arquillian Cube 1.1.0 has been released with new features and few bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Possibility for other custom strategies besides pass:[<code>customAwaitStrategy</code>]*

BeforeStop events can be very restrictive at times. Now you can write your own pass:[<code>BeforeStop</code>] logic. To implement a custom before stop logic, you need to create a class implementing pass:[<code>org.arquillian.cube.spi.beforeStop.BeforeStopAction</code>] and registering it on cube definition.

[listing,role="prettify",subs=verbatim]
----
public class CustomBeforeStopActionImpl implements BeforeStopAction {
 
   private DockerClientExecutor dockerClientExecutor;
   private String containerID;
 
   @Override
   public void doBeforeStop() {
     //Logic
  }
}
----

Registration of previous action.

[listing,role="prettify",subs=verbatim]
----
tomcat:
   image: tutum/tomcat:7.0
   beforeStop:
    - customBeforeStopAction:
      strategy: org.arquillian.cube.docker.impl.beforeStop.CustomBeforeStopActionImpl
----

pass:[<i class="icon-star">]pass:[</i>] *Add possibility to ignore docker-compose location / (and default ones)*

New cube property has been added to disable the cube definitions. This is useful if you are using container objects for testing and you’ve got a pass:[<code>docker-compose</code>] on default locations and you won’t to be used by cube.

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="docker">
   <property name="ignoreContainersDefinition">true</property>
</extension>
----

By default its value is false.
