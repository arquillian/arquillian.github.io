= Arquillian Governor 1.0.1.Final Released
:sectids!:

A new member has been added to Governor:

[discrete]
=== Arquillian Governor Ignore

This extension simply ignores (skips) test methods which are listed in pass:[<code>arquillian.xml</code>].

Configuration of this extension is done via pass:[<code>governor-ignore</code>] qualifier:

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="governor-ignore">
    <property name="expression">com\.foobar\.[.]*</property>
    <property name="methods">org.acme.foo.ListTest#testStrFilter,org.bar.boo.QwertTest#testFoo</property>
    <property name="methods_1">org.arquillian.test.governor.ignore.IgnoreTest#testIgnored</property>
</extension>
----

The pass:[<code>expression</code>] property is a regexp to which it matches simple method’s fqn.

The pass:[<code>methods</code>] property contains a list of simple fqn’s, separated by comma (,), where any property starting with pass:[<code>methods_</code>] is a separate simple fqn.

Of course all properties are optional. But in order to ignore something, at least one must be defined. ;-)
