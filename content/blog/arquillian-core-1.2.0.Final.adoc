=== Welcome JUnit Rules for Arquillian

Just before Christmas holidays we are extremely excited to ship long awaited feature for JUnit integration. If you want to use Arquillian Testing Platform with other JUnit Runner, you can now use JUnit Rules – pass:[<code>ArquillianTestClass</code>] and pass:[<code>ArquillianTest</code>] – and happily let Arquillian do the heavy lifting for your tests. Hats off to https://twitter.com/ahus1de[Alexander Schwartz] for providing initial implementation.

To get the similar functionality what the pass:[<code>@RunWith(Arquillian.class)</code>] is offering you should require both rules i.e. pass:[<code>ArquillianTestClass</code>] and pass:[<code>ArquillianTest</code>].

[listing,role="prettify",subs=verbatim]
----
@ClassRule
public static ArquillianTestClass arquillianTestClass = new ArquillianTestClass();

@Rule
public ArquillianTest arquillianTest = new ArquillianTest();

@Deployment
public static JavaArchive createDeployment() {
    return ShrinkWrap.create(JavaArchive.class)
        .addClass(Greeter.class)
        .addAsManifestResource(EmptyAsset.INSTANCE, "beans.xml");
}

@Inject
Greeter greeter;

@Test
public void should_greet_earthlings() throws Exception {
    String name = "Earthlings";
    Assert.assertEquals("Hello, " + name, greeter.greet(name));
}
----

In order to use any other JUnit Class or Method Rule with pass:[<code>ArquillianClassTest</code>] or pass:[<code>ArquillianTest</code>] rule, you have to use it with pass:[<code>RuleChain</code>] having arquillian rules defined as outer rules.. e.g.

[listing,role="prettify",subs=verbatim]
----
@Rule
public MethodRule testWatchman = MethodRuleChain.outer(new ArquillianTest().around(new TestWatchman());
----

There is no chain for method rules https://github.com/junit-team/junit4/issues/383#issuecomment-5056440[out of the box provided by JUnit] so we have our own and you can use it if you need.

If you would like to see it in action, take a look at following examples

* https://github.com/arquillian/arquillian-cube/pull/913/files[Using Arquillian JUnit rule with Cube]
* https://github.com/arquillian/arquillian-graphene/pull/176/files[Using Arquillian JUnit rules with Graphene]
