= Arquillian Cube Extension 1.14.0 Released
:sectids!:

We are delighted to announce a new version of Arquillian Cube 1.14.0 with a bunch of awesome features and bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Istio Support*

We have added Istio support so you can annotate your class with pass:[<code>@IstioResource</code>] to apply an Istio resource. Alternatively, if you prefer using programmatic way we have provided pass:[<code>IstioAssistant</code>]. To use it you need to import following dependency:

[listing,role="prettify",subs=verbatim]
----
<dependency>
  <groupId>org.arquillian.cube</groupId>
  <artifactId>arquillian-cube-istio-kubernetes</artifactId>
  <version>${version}</version>
  <scope>test</scope>
</dependency>
----

Same dependency can be used either with Kubernetes or OpenShift.

https://github.com/arquillian/arquillian-cube/tree/master/openshift/ftest-istio-openshift[Here] you can see a full example.

pass:[<i class="icon-star">]pass:[</i>] *Allow OpenShift Template to use resources on classpath*

You can define OpenShift Templates as classpath resources using pass:[<code>classpath:</code>] protocol. pass:[<code>@Template(url = &quot;classpath:hello-template.yaml&quot;)</code>]

pass:[<i class="icon-star">]pass:[</i>] *Create OpenShift Template DSL for OpenShiftAssistant*

We have added a new capability to pass:[<code>OpenShiftAssistant</code>] so you can apply OpenShift Templates programmatically.

[listing,role="prettify",subs=verbatim]
----
openShiftAssistant
    .usingTemplate(getClass().getClassLoader().getResource("hello-template.yaml"))
    .parameter("RESPONSE", "Hello from Arquillian Template")
.deploy();
----

You can see a full example at https://github.com/arquillian/arquillian-cube/tree/master/openshift/ftest-openshift-assistant-template[OpenShiftAssistant Template creation]

pass:[<i class="icon-star">]pass:[</i>] *Add pass:[<code>@Template</code>] annotation in test method scope*

Now you can use pass:[<code>@Template</code>] at the method level, so the template is applied before executing the test method and everything applied from that template removed after the test is finished.

pass:[<i class="icon-star">]pass:[</i>] *Simplify dependencies for standalone mode*

With this version we have added three new dependencies which simplify the usage of Cube. Since almost all tests written in Cube are using pass:[<code>arquillian-standalone</code>] mode, instead of having to define both pass:[<code>arquillian-standalone</code>] and pass:[<code>arquillian-cube</code>], we created a starter dependency which registers both.

In case of using Cube Docker:

[listing,role="prettify",subs=verbatim]
----
<dependency>
    <groupId>org.arquillian.cube</groupId>
    <artifactId>arquillian-cube-docker-starter</artifactId>
    <scope>test</scope>
</dependency>
----

In case of using Cube Kubernetes:

[listing,role="prettify",subs=verbatim]
----
<dependency>
    <groupId>org.arquillian.cube</groupId>
    <artifactId>arquillian-cube-kubernetes-starter</artifactId>
    <scope>test</scope>
</dependency>
----

In case of using Cube OpenShift:

[listing,role="prettify",subs=verbatim]
----
<dependency>
    <groupId>org.arquillian.cube</groupId>
    <artifactId>arquillian-cube-openshift-starter</artifactId>
    <scope>test</scope>
</dependency>
----
