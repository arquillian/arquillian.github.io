= Arquillian Cube Extension 1.11.0 Released
:sectids!:

pass:[p.] We are delighted to announce a new version of Arquillian Cube 1.11.0 with a new integration to another Arquillian project and bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Integration between Graphene and OpenShift*

We have created an integration between http://arquillian.org/arquillian-graphene/[Arquillian Graphene] and Arquillian Cube OpenShift.

Now, if you are using Arquillian Graphene (in http://arquillian.org/arquillian-graphene/#arquillian-mode-options[standalone mode]) together with Arquillian Cube OpenShift, the base URI of Graphene is automatically set to the URL specified in OpenShift pass:[<code>Route</code>].

You can configure a specific pass:[<code>URL</code>] using the pass:[<code>url</code>] property from pass:[<code>graphene</code>] configuration. In this case, the hostname is going to be resolved as OpenShift pass:[<code>route</code>] name, and if there is no pass:[<code>route</code>] with that name, then pass:[<code>URL</code>] is treated as is. For example:

[listing,role="prettify",subs=verbatim]
----
<extension qualifier="graphene">
  <property name="url">http://hello-world:8080</property>
</extension>
----

In the previous example, this integration will try to find an OpenShift pass:[<code>route</code>] with name pass:[<code>hello-world</code>] and inject its IP. If there is no pass:[<code>route</code>] with that name, then the pass:[<code>url</code>] field is considered to be the final pass:[<code>URL</code>].

You can see full example at https://github.com/arquillian/arquillian-cube/tree/master/openshift/ftest-openshift-graphene[Graphene example]

Many thanks to https://github.com/iocanel[Ioannis Canellos] for his help in most of the bugfixes.
