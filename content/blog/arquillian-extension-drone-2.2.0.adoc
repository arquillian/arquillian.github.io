= Arquillian Drone Extension 2.2.0 Released
:sectids!:

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"]

Apart from several fixes this release brings two improvements:

[discrete]
==== pass:[<i class="icon-star">]pass:[</i>] Property for skipping creation of @Drone instances

We introduced a system property pass:[<code>arquillian.drone.skip.creation</code>]. If you set the property to pass:[<code>true</code>] then Drone skips the creation/injection of *pass:[@]Drone* instances. This property is checked in a *pass:[@]Before* phase, so you can modify the property during the test execution.

[discrete]
==== pass:[<i class="icon-star">]pass:[</i>] ChromeHeadless browser property

Since Chrome 59 it is possible to use headless mode. To do it in Drone, it was necessary to set pass:[<code>chromeArguments</code>] to pass:[<code>--headless</code>]:

[listing,role="prettify",subs=verbatim]
----
<property name="browser">chrome</property>
<property name="chromeArguments">--headless</property>
----

This release simplifies the process by introducing a new browser property value: pass:[<code>chromeHeadless</code>]. If you use the value as a browser property:

[listing,role="prettify",subs=verbatim]
----
<property name="browser">chromeHeadless</property>
----

the arguments are automatically set, so the browser will be launched in the headless mode.
