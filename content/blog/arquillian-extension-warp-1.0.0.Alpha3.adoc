= Arquillian Warp 1.0.0.Alpha3 Released
:sectids!:

Warp Alpha3 is a last stop to Beta releases which brings mainly enhancements and bug fixes, but also a pretty new documentation:

[discrete]
=== Documentation Draft

Even though a https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#architecture[documentation draft] isn’t published yet to the Arquillian site, it is almost completed.

This documentation describes; where https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#what-is-warp[Warp’s place in a space of integration testing], how to https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#how-to-use-warp[start with Warp in your project], what features are supported by https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#warp-api[Warp API] and few words about https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#debugging-warp[debugging tests] and an https://github.com/lfryc/arquillian.github.com/blob/warp-docs/docs/warp.adoc#architecture[extension architecture].

[discrete]
=== Highlighted Enhancements

pass:[<i class="icon-star">]pass:[</i>] Jacoco Support::
+
--
Thanks to https://github.com/atzoum[Aris Tzoumas], Warp users can now enjoy coverage reporting using link:/modules/jacoco-extension[pass:[<code>arquillian-extension-jacoco</code>]]. But the contribution was bigger than just that since it enabled a lot of other features.
--



pass:[<i class="icon-star">]pass:[</i>] Meaningful Reporting::
+
--
The concepts Warp builds upon aren’t really complex, however the implementation needs to make sure that users can understand when something breaks. Warp tries to add as much contextual information as needed to overcome common issues together with a hint on how to resolve an issue.

We hope to improve reporting even more, but here we rely on you – don’t hesitate to report to us when your experience with Warp isn’t as smooth as it should be.
--



pass:[<i class="icon-star">]pass:[</i>] JSF Managed Beans Injection::
+
--
You can now inject any managed artifact through EL expressions using standard pass:[<code>ManagedProperty</code>] annotation:

[listing,role="prettify",subs=verbatim]
----
@ManagedProperty("#{facesContext.application}") Application application;
@ManagedProperty("#{myBean}") SomeFacesBean myBean;
----
--

[discrete]
=== SPI enhancements

pass:[<i class="icon-star">]pass:[</i>] Independent Bi-directional Communication::
+
--
During the pass:[<code>Alpha3</code>] development we have identified many common problems which came down to basics that pass:[<code>Alpha2</code>] was built upon: piggy-backing on HTTP request/response and wrapping pass:[<code>HttpServletResponse</code>].

In order to overcome those problems, Warp now leverages an internal SPI for bi-directional direct communication between test and server (originally created by Aris as a way to support Jacoco).

This is a fundamental change as it changes the way Warp transfers inspections and it also opens up to completely new possibilities by creating a tigher relationship between a test and a server.
--

[discrete]
=== Important Bug Fixes

pass:[<i class="icon-star">]pass:[</i>] Do not interfere with non-Warp tests::
+
--
Warp Alpha2 wasn’t really a good citizen and it tried to hook into all tests even though they weren’t annotated with pass:[<code>@WarpTest</code>]. Those problems should now be addressed.
--

[discrete]
=== Enjoy the Release

Alpha3 comes with lot of enhancements which improves the user experience, but it also brings some improvements which were needed to support rising https://community.jboss.org/thread/213247[REST] and http://docs.jboss.org/seam/2.0.1.GA/reference/en/html/testing.html[SeamTest] migration layer extensions driven by https://github.com/jmnarloch/[Jakub Narloch] and https://github.com/maschmid[Marek Schmidt].

Let us know if we can smoothly enter a Beta releases train!
