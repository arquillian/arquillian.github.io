= Arquillian Drone Extension 2.0.0.Beta1 Released
:sectids!:

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"]

This release is (hopefully) the last step before the final release of the second generation of the Arquillian Drone extension.

[discrete]
=== Significant changes and additions

pass:[<i class="icon-star">]pass:[</i>] Support for Drone webdriver injection in pass:[<code>@BeforeClass</code>]

pass:[<i class="icon-star">]pass:[</i>] Drones with a deployment scoped life cycle are now more tightly connected to the deployment – it’s creation has been postponed to the pass:[<code>@AfterDeploy</code>] phase

pass:[<i class="icon-star">]pass:[</i>] Some SPI event have been merged/replaced::
+
--
The following events:

* BeforeDroneCallableCreated
* AfterDroneConfigured
* BeforeDroneConfigured
* AfterDroneCallableCreated

are now merged into:

* BeforeDronePrepared
* AfterDronePrepared

They are called before/after both the Drone configuration and the Drone callable instance are prepared. This ensures that both or none of the objects should be present.
--
