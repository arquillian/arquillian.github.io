= Arquillian Cube Extension 1.4.0 Released
:sectids!:

New version of Arquillian Cube 1.4.0 has been released with new features and bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Allow star operator in Container Object DSL*

Now you can use star operator to generate random container names nad binding ports in Container Object DSL too.

[listing,role="prettify",subs=verbatim]
----
@ClassRule
public static ContainerDslRule redisStar = new ContainerDslRule("redis:3.2.6", "redis*")
                                            .withPortBinding(6379);
----

In previous example a container with random name starting with pass:[<code>redis</code>] is started and a random binding port is used. Notice that this allows parallel execution of tests against same docker host. You can read more about star operator at http://arquillian.org/arquillian-cube/#_parallel_execution[Parallel Execution] for more information about it.

pass:[<i class="icon-star">]pass:[</i>] *Uses latest version of wait-for-it algorithm*

Copied https://github.com/vishnubob/wait-for-it/commit/8f52a814ef0cc70820b87fbf888273f3aa7f5a9b[latest] pass:[<code>wait-for-it.sh</code>] script into Arquillian Cube.
