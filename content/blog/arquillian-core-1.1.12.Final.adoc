= Arquillian Core 1.1.12.Final Released
:sectids!:

Just before Christmas we have shipped new version of Arquillian Core. This is not a major release but besides typical dependency updates it comes with few a important improvements we wanted to share with you.

[discrete]
=== Highlights in this release

pass:[<i class="icon-star">]pass:[</i>] Improved support for injection in pass:[<code>JUnit @Rules</code>]::
+
--
In the previous version we provided initial support for injection in pass:[<code>JUnit @Rules</code>]. It was limited to client side execution but now we support in-container part of test execution as well. This means you can have custom rules having access to injectable components when running in-container tests (both from your application as well as those provided by Arquillian).

If you want to see it in action, we created examples in the https://github.com/arquillian/arquillian-showcase/tree/1280bc2d59478105fdfb17e7baf94706ecabee66/junit-rules[showcase project].
--



pass:[<i class="icon-star">]pass:[</i>] Synthetic bridge methods (JDK 8 issue)::
+
--
Some of the extensions compiled using JDK 6 can manifest http://bugs.java.com/view_bug.do?bug_id=6695379[JDK 8 problem]. This might result with pass:[<code>ClassCastExceptions</code>] which might be very confusing for the user. We have provided https://issues.jboss.org/browse/ARQ-2042[fix for it] in this release.
--



pass:[<i class="icon-star">]pass:[</i>] Combining multiple errors::
+
--
When test fails with multiple errors (as it happens in link:/blog/2017/01/05/arquillian-algeron-1-0-0-Alpha5/[Arquillian Algeron verification] for instance) Arquillian will provide combined exception having all the faults captured.
--
