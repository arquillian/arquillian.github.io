=== Significant changes and additions:

pass:[<i class="icon-star">]pass:[</i>] Upgraded Selenium to 3.5.3

pass:[<i class="icon-star">]pass:[</i>] Added ability to explicitly specify the target architecture of the IE web-driver binary. To do it, use the property pass:[<code>ieDriverArch</code>] with any of the two possible values: pass:[<code>Win32</code>] and pass:[<code>x64</code>]. If the property is not specified then the architecture is resolved from the host OS. Big thanks to https://github.com/vmuzikar/[Václav Muzikář] for implementing it.
