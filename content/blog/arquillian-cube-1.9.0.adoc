= Arquillian Cube Extension 1.9.0 Released
:sectids!:

New version of Arquillian Cube 1.9.0 has been released with new features and bug fixes.

[discrete]
=== What’s new

pass:[<i class="icon-star">]pass:[</i>] *Add support for network aliases*

Add support for network aliases in pass:[<code>docker compose</code>] format https://docs.docker.com/compose/compose-file/#aliases[docker-compose aliases].

pass:[<i class="icon-star">]pass:[</i>] *Disable OpenShift ImageStream detection by default*

New flag has been added to enable/disable the detection of OpenShift Image Streams. These files must be located at pass:[<code>target</code>] directory and their names should end with pass:[<code>-is.yml</code>].

By default this detection is disabled hence these files are not processed. If you want to enable you need to set OpenShift configuration parameter pass:[<code>enableImageStreamDetection</code>] to true.

You can read more about this parameter at http://arquillian.org/arquillian-cube/#_openshift_configuration_parameters[Arquillian Cube documentation]

Many thanks to https://github.com/georgwolf[Georg Wolf], https://github.com/jensstn[Jens] and https://github.com/Ladicek[Ladislav Thon] for their help.
