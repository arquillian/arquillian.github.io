= Arquillian Portal Extension 1.0.0.CR1 Released
:sectids!:

// Historical interpolation #{site.project_space} = http://community.jboss.org/en/arquillian from https://arquillian.org/blog/2013/09/26/arquillian-extension-portal-1-0-0-CR1/ (captured 2026-11-13).

There are several important fixes in this release for those testing portlets with Arquillian.

[discrete]
=== Some of the highlights in this release

pass:[<i class="icon-star">]pass:[</i>] Fix exceptions where there are multiple portlet deployments present on a Test class.

pass:[<i class="icon-star">]pass:[</i>] Allow pass:[<code>@PortalURL</code>] to be present on a test method parameter, in addition to a field.

pass:[<i class="icon-star">]pass:[</i>] Modify the parsing of portlet.xml to occur for each test instead of once per Test class.

We look forward to hearing your feedback about this release in the http://community.jboss.org/en/arquillian[community forums]!
