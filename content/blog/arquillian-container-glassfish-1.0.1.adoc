= Arquillian Container GlassFish 1.0.1 Released
:sectids!:

[discrete,role="highlights"]
=== Some of the highlights in this release

[discrete]
==== Ability to define wait time before connecting to the container

In some cases you might want to define wait time before trying to connect to the GlassFish container. For this purpose we have introduce simple configuration. Thanks https://github.com/ankathur[Ankur Kathuria] for helping out.

[.filename]
arquillian.xml

[listing,role="prettify",subs=verbatim]
----
 <container qualifier="glassfish" default="true">
  <configuration>
    <property name="waitTimeMs">200</property>
    <property name="retries">5</property>
  </configuration>
</container>
----

* pass:[<code>waitTimeMs</code>] defines how many miliseconds Arquillian will wait before trying to connect to the container
* pass:[<code>retries</code>] defines how many attempts should be made with pass:[<code>waitTimeMs</code>] intervals

[discrete]
==== Minor bug fixes

Thanks to https://github.com/mirko-lelansky[Mirko Lelansky] we have improved usage of GlassFish CLI.
