:sectids!:

image:/images/blog/drone_400.png[alt="",role="graphic pull-right"]

Apart from several component updates, bug fixes and improvements; this release provides also one new feature:

[discrete]
==== Fullscreen

If you want to open your browser in fullscreen mode, use any of the following strings: pass:[<code>full</code>], pass:[<code>fullscreen</code>] and pass:[<code>max</code>] as a value of the arquillian.xml property: pass:[<code>dimensions</code>] +
For more information about configuration possibilities, see the http://arquillian.org/arquillian-extension-drone/#configuring-drone-instances[documentation]
