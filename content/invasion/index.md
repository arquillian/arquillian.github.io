# The Arquillian Invasion

## Our Mission

Arquillian is on a mission to rid the Java universe of bugs. We're doing this by enabling developers to easily test their applications in the environments where they'll eventually run.

## The Problem

For too long, Java developers have been forced to choose between writing tests that run in the container but are hard to debug, or writing tests that run outside the container but don't accurately reflect how the application will behave in production.

## The Solution

Arquillian brings your test to the runtime so you can focus on testing your application's behavior rather than managing the runtime. Using Arquillian, you can develop a comprehensive suite of tests from the convenience of your IDE and run them in any IDE, build tool or continuous integration environment.

## Join the Invasion

Arquillian is an open source project, and we welcome contributions from the community. Here's how you can join the invasion:

- **Use Arquillian**: The best way to support Arquillian is to use it in your projects and spread the word.
- **Report bugs**: If you find a bug, please report it on our [issue tracker](https://issues.jboss.org/browse/ARQ).
- **Contribute code**: Fork the repository, make your changes, and submit a pull request.
- **Join the discussion**: Join the [Arquillian forum](http://community.jboss.org/en/arquillian) to discuss ideas and ask questions.
- **Spread the word**: Tell others about Arquillian and how it has helped you.

## The Arquillian Universe

The Arquillian Universe is a collection of projects that work together to provide a comprehensive testing platform for the JVM. The core of the Arquillian Universe is the Arquillian Core project, which provides the foundation for all other projects.

Other projects in the Arquillian Universe include:

- **ShrinkWrap**: A Java API for creating archives (JAR, WAR, EAR) programmatically.
- **Drone**: Browser automation and WebDriver integration.
- **Graphene**: Rich WebDriver extensions and Ajax support.
- **Persistence**: Database testing.
- **Cube**: Docker container integration.
- **Chameleon**: Simplified container configuration.
- **Algeron**: Consumer-driven contract testing.
- **Smart Testing**: Intelligent test execution order.
