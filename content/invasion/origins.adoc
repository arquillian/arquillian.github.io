Arquillian originated from the link:http://docs.jboss.org/cdi/tck/reference/1.0.1-Final/html/test-harness.html[JBoss Test Harness], a utility created by Pete Muir as the foundation of the JSR-299 and JSR-303 TCKs. The JBoss Test Harness prototyped a solution that provided:
  
* *Declarative, annotation-driven assembly of archives.* ShrinkWrap provides a fluent Java API for assembling JAR, WAR, and EAR archives.
* *A Java Adapter API.* Container adapters can start and stop a container and deploy a test.
* *Easy switching between in-container and standalone mode.* Arquillian treats these as different container types.
* *Packaging of the test case alongside the archive.* The test and infrastructure move to the server for in-container execution.
* *A pluggable test executor.* The framework selects in-container or standalone execution for the same test.

  It quickly became obvious that this was something that could be really useful to other people outside of the CDI TCK and Bean Validation TCKs.

== The formation of Arquillian
  
Since Pete had hacked on the JBoss Test Harness under pressure to start the CDI TCK, the plan was to take its best ideas and start fresh. In late 2009, Aslak Knutsen began prototyping a new framework inside the Weld codebase called Weld Test. Aslak and Pete combined ideas from JBoss Test Harness and Weld Test with ShrinkWrap, with help from Andrew Rubinger. The result was a portable, pluggable test framework with a new name: Arquillian.
 
Since then, support has been added for additional containers, test enrichment, and test framework integrations. Arquillian became the foundation of test suites in link:http://sfwk.org/Seam3[Seam 3] modules and examples and was adopted as a replacement for the JBoss Test Harness.

== JBoss Testing

Arquillian is part of the link:https://community.jboss.org/groups/testing[JBoss Testing SIG], an effort to unify testing-related projects in the JBoss Community. The initiative is led by the JBoss Testing Guild, Aslak Knutsen, Dan Allen, and Andrew Rubinger.

== Contributions

Significant contributions have come from the Quality Engineering team at Red Hat, including Drone and Graphene.
  
The original Arquillian artwork, most notably Ike, was created by Cheyenne Weaver. The story and artwork evolved through the work of community member and content strategist Sarah White.

== About the name

The project name may or may not be related to the alien species from a popular movie about protecting the Earth from alien scum. We want to protect you from infrastructure scum in your integration tests. _Death to all bugs!_
