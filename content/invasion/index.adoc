Arquillian is an innovative and highly extensible testing platform for the JVM that enables developers to easily create automated integration, functional, and acceptance tests for Java middleware.

Picking up where unit tests leave off, Arquillian handles container management, deployment, and framework initialization so you can focus on writing your tests. *Real tests*. In short...

== Arquillian makes integration testing a breeze!

Arquillian brings the test to the runtime so you do not have to manage the runtime from the test or the build. It covers all aspects of test execution:

* Managing the lifecycle of the container or containers
* Bundling the test case, dependent classes, and resources into a ShrinkWrap archive
* Deploying the archive to the container
* Enriching the test case with dependency injection and other declarative services
* Executing the tests inside or against the container
* Capturing results and returning them to the test runner

Arquillian integrates with familiar testing frameworks such as JUnit 4 and TestNG 5, allowing tests to run from existing IDE, Ant, and Maven test plugins without add-ons.

== Guiding Principles

The Arquillian project adheres to three core principles:

* *Tests should be portable to any supported container.* Container-specific APIs stay out of tests so applications can be verified across containers.
* *Tests should be executable from both the IDE and the build tool.* IDE support provides fast turnaround without sacrificing continuous integration.
* *The platform should extend or integrate existing test frameworks.* An extensible architecture encourages reuse and fosters a unified Java testing ecosystem.

Regardless of how complex it becomes, executing an Arquillian test is as simple as selecting “Run As > Test” in the IDE or executing the `test` goal from the build tool.
