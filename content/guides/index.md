# Arquillian Guides

Welcome to the Arquillian guides. These guides provide step-by-step instructions for common tasks and use cases. They're a great way to get started with Arquillian.

## Beginner Guides

These guides are designed for developers who are new to Arquillian. They cover the basics of setting up Arquillian and writing your first tests.

### [Getting Started](/guides/getting-started/)

Learn how to add Arquillian to the test suite of your project and write your first Arquillian test.

### [Getting Started: Rinse and Repeat](/guides/getting-started-rinse-and-repeat/)

A follow-up to the Getting Started guide that covers more advanced topics like exporting deployments and using remote containers.

### [Get Started Faster with Forge](/guides/get-started-faster-with-forge/)

Learn how to use JBoss Forge to quickly set up Arquillian in your project.

## Intermediate Guides

These guides cover more advanced topics and are designed for developers who are already familiar with the basics of Arquillian.

### [Testing Java Persistence](/guides/testing-java-persistence/)

Learn how to test JPA applications with Arquillian.

### [Functional Testing Using Graphene](/guides/functional-testing-using-graphene/)

Learn how to test web applications with Arquillian Graphene.

### [Testing in the Cloud](/guides/testing-in-the-cloud/)

Learn how to test applications in cloud environments with Arquillian.

## Advanced Guides

These guides cover advanced topics and are designed for developers who are already familiar with Arquillian and want to extend it or use it in more complex scenarios.

### [Developing a Container Adapter](/guides/developing-a-container-adapter/)

Learn how to develop a container adapter for Arquillian.

### [ShrinkWrap Introduction](/guides/shrinkwrap-introduction/)

Learn how to use ShrinkWrap to create test deployments programmatically.
