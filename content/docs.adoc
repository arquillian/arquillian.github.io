== Individual Modules

Arquillian is organized into modules for test runners, deployments, containers, extensions, and supporting tools. The generated module directory will be populated by the Java provider in Phase 4.

== Core Concepts

=== Test runners

Arquillian supports the two most popular Java test frameworks:

* JUnit 4 and above
* TestNG 5 and above

JUnit tests use `@RunWith(Arquillian.class)` and TestNG tests extend the Arquillian base class. Existing IDE, Ant, Maven, and Gradle integrations continue to run the tests without additional add-ons.

=== Deployments

ShrinkWrap lets a test define a deployment archive declaratively in Java code. Arquillian deploys that micro-deployment to the container before the test runs, so only the classes and resources needed by the scenario are visible.

=== Test enrichers

Arquillian enriches the test class with injection, lifecycle callbacks, and contexts. CDI, resource, EJB, and persistence injection are available in supported Java EE environments.

=== Containers

The test class does not reference a specific container. Arquillian supports remote, managed, and embedded interaction styles across application servers, servlet containers, bean containers, and OSGi runtimes.

=== Run modes

Tests can run in-container or as a client of a deployed archive. These modes can be mixed to cover application, web, and service behavior.

=== Extensions

Arquillian exposes extension points for integrations that customize deployment, execution, reporting, and the test environment.
