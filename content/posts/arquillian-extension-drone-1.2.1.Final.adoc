This release brings Safari support, inheritance bugfixes and minor improvements for reusable browsers. Additionally, Selenium version was updated to 2.37.1, so you can enjoy latest browsers out of the box. Don't forget to check our link:https://docs.jboss.org/author/display/ARQ/Drone.[documentation]

<br/>

=== What's new in Drone since 1.2.0.Final?

- <i class="icon-star"></i> Safari support :=
Drone is now able to inject Safari browser. Kudos for implementing this feature goes to Jiří Locker! Usage is as easy as you would expect.

arquillian.xml

[source]
----
<extension qualifier="webdriver">
    <property name="browser">safari</property>
</extension>
=:
----
