New version of Arquillian Cube 1.2.0 has been released with new features and few bug fixes.

=== What's new

<i class="icon-star"></i> **Adds annotation for sleeping before each test**

You can annotate a class with `Sleep` annotation so before starting executing the tests, the execution is slept by the amount of milliseconds set there.

This annotation also supports timespan format. For example `Sleep("1m30s")` set a waiting of 1 minute and a half.

<i class="icon-star"></i> **Add support for `HealthCheck annotation`**

p. You can annotate a class with `HealthCheck` annotation so before starting executing the tests, the execution is slept until the health check passes.

For example `HealthCheck("/myservice/healthcheck")` waits until the given endpoint returns an Http Code 200.

<i class="icon-star"></i> **JUnit Rule for Container Object DSL approach**

Now you can use Container Object DSL without `Arquillian` runner. You only need to use a `JUnit Rule` for this purpose.

[source]
----
@ClassRule
 public static ContainerDslRule redis = new ContainerDslRule("redis:3.2.6")
                                            .withPortBinding(6379);
----
Before executing test class, a new Docker container using Redis image is boot up and stopped after all tests.
