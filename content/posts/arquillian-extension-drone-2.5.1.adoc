The Arquillian team is proud to announce the *2.5.1* release of the Arquillian Drone Extension component!

=== What is Arquillian?

Arquillian is open source software that empowers you to test JVM-based applications more effectively. Created to defend the software galaxy from bugs, Arquillian brings your test to the runtime so you can focus on testing your application's behavior rather than managing the runtime.
