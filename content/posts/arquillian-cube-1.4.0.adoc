New version of Arquillian Cube 1.4.0 has been released with new features and bug fixes.

=== What's new

<i class="icon-star"></i> **Allow star operator in Container Object DSL**

Now you can use star operator to generate random container names nad binding ports in Container Object DSL too.

[source]
----
@ClassRule
public static ContainerDslRule redisStar = new ContainerDslRule("redis:3.2.6", "redis*")
                                            .withPortBinding(6379);
----
In previous example a container with random name starting with `redis` is started and a random binding port is used. Notice that this allows parallel execution of tests against same docker host. You can read more about star operator at link:http://arquillian.org/arquillian-cube/#_parallel_execution[Parallel Execution] for more information about it.
