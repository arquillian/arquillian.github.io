If you think doing integration testing is significantly slower, complex or just plain harder than unit testing, think again. In this video, link:https://github.com/aslak[Aslak] shows how quickly you can go from an empty directory (0mph) to a project that runs a CDI test inside a managed link:http://jboss.org/as7[JBoss AS 7] container (60mph) in under a minute using the link:http://github.com/forge/plugin-arquillian[Arquillian plugin] for link:http://jboss.org/forge.[JBoss Forge]

div. link:http://vimeo.com/22696384[Arquillian + Seam Forge 0-60 in under a minute] by Aslak Knutsen on Vimeo.

video. vimeo 22696384 600x480

Notice that the test cold boots JBoss AS 7, deploys the tests and runs it in-container, then undeploys and shuts down the server in < 5 seconds. (It runs even faster when you take away the Maven cycle).

A quote by link:https://github.com/bleathem[Brian Leathem] is suitable for quoting here:

[quote]
____
With tools like Arquillian, Shrinkwrap, [and] in-memory databases, [we] are busting through the old barriers of terms like unit and integration tests. Perhaps we need a new term for them: "real tests" or "useful tests" are two possibilities that come to mind.
____
Don't mock. Test for real.
