New version of Arquillian Cube 1.5.0 has been released with new features and bug fixes.

=== What's new

<i class="icon-star"></i> **Set System Properties with Docker container information**

When running a test next System Properties should be available:

* `arq.cube.docker.host` setting the docker host ip.

And for each docker container defined:

* `arq.cube.docker.<cube_id>.ip` with container ip.
* `arq.cube.docker.<cube_id>.internal.ip` with container internal ip.
* `arq.cube.docker.<cube_id>.port.<exposed_port>` with binding port of giving exposed port.
