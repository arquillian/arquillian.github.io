# Arquillian Community

Arquillian is an open source project, and we welcome contributions from the community. Here's how you can get involved:

## Discussion

- **Forum**: Join the [Arquillian forum](http://community.jboss.org/en/arquillian) to discuss ideas and ask questions.
- **IRC**: Join the [#arquillian](irc://irc.freenode.org/arquillian) IRC channel on Freenode.
- **Twitter**: Follow [@arquillian](https://twitter.com/arquillian) on Twitter for the latest news and updates.

## Reporting Issues

If you find a bug or have a feature request, please report it on our [issue tracker](https://issues.jboss.org/browse/ARQ).

## Contributing Code

Arquillian is hosted on GitHub. You can find all our repositories at [github.com/arquillian](https://github.com/arquillian).

To contribute code:

1. Fork the repository you want to contribute to.
2. Create a branch for your changes.
3. Make your changes and commit them.
4. Push your changes to your fork.
5. Submit a pull request.

Please make sure your code follows our coding standards and includes tests.

## Contributors

Arquillian is developed by a community of contributors. You can see a list of all contributors on our [contributors page](/community/contributors).

## Nobles

The Arquillian Nobles are the core team members who guide the project. They are responsible for reviewing pull requests, making architectural decisions, and ensuring the project's long-term success.

You can see a list of all Nobles on our [nobles page](/community/nobles).

## Web Chat

Join our [web chat](/community/webchat) to talk with other Arquillian users and developers in real-time.

## Testing SIG

The [Testing SIG](https://community.jboss.org/groups/testing) (Special Interest Group) is a community of developers interested in testing Java applications. The group discusses testing strategies, tools, and best practices, with a focus on Arquillian and related projects.

## JBoss Community

Arquillian is a [JBoss Community](http://jboss.org) project and development is sponsored by Red Hat, Inc.
